## [1.0.0] - 2026-10-15

### Added
- First English release of the **Claude Code Efficiency Guide**.
- Practical guidance on token usage, context management, prompt caching,
  model selection, reasoning effort, and efficient coding workflows.
- Guidance for `CLAUDE.md`, on-demand skills, MCP tools, subagents, and hooks.
- Examples and reusable workflows for development tasks, including
  WordPress, TypeScript, and Electron scenarios.
- Session-maintenance tips, troubleshooting guidance, and efficiency checklists.
- `LICENSE` describing the CC BY 4.0 documentation license.
- `CONTRIBUTING.md` with contribution guidelines, evidence standards,
  and an invitation for community improvements.

### Notes
- Savings and performance depend on workload, configuration, versions,
  and quality requirements. No fixed percentage of savings is guaranteed.
- Commands and model capabilities may change; users should consult current
  official documentation before applying version-sensitive instructions.
